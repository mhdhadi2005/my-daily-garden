# Permanent garden growth

My Daily Garden v2 uses cumulative garden points. Completing a tree adds it permanently to the reader's forest and starts the next tree without subtracting points. This replaces the prototype's reset-on-harvest model because lasting progress and stable tree identity support the personal woodland readers are meant to return to. The game has not launched, so there is no production garden history to migrate; a separate launch policy will acknowledge earlier newsletter activity without presenting it as prior game progress.
